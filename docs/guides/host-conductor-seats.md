# Host conductor seats (pointer)

Conductor / ops **seats** live in the **host** Grok Bot workflows, not in this template tree.
DevEnvTemplate does **not** vendor those seat skills.

## What DET provides

Portable guides and extras skills (testing-standards, automation-harness, research-prompt-contract,
pin-and-branch-hygiene). Adopters wire their own host seats on top.

## Named host practices (not vendored here)

Hosts commonly name these as seat habits — DET only names them; it does not ship the skill bodies:

- **research-before-Do** — ACCEPT a Research EXIT before Implement.
- **anti-ladder** — do not skip SCOUT / Lead gate for tool installs.
- **one digest per Act** — one concise status digest per Act cycle (not a chat dump).

## Forbidden

- Copying host Co seat skill trees into DET.
- Dumping seat procedure bodies into `AGENTS.md`.
- Binding DET docs to a single host product phase board or CAP park.
