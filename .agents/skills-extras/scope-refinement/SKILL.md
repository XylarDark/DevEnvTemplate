# Scope refinement

**Protocol:** [scope-refinement.md](../../../docs/human-use/scope-refinement.md)

> **Localize on copy.** Rounds and the taste profile live in the host. Do not invent the slice.

1. Read the host profile. Locked forks are not questions.
2. Name the fork. Use Hard Parts for scope or quanta. Use Ousterhout for a module inside a settled quantum.
3. Each question is a real fork. Recommend one option that the host files already support, or recommend Skip.
4. Stage a candidate through the host taste-profiler before asking. Do not write the durable profile yet.
5. Ask through the Cursor structured question picker, max 2 questions, include Skip, then stop. Do not paste a markdown menu.
6. After the human answers, promote that pick or reject on Skip. Skip does not advance the round.
7. If a question was too thin, retire that wording with a dated note. Do not delete it.
